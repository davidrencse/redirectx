# RedirectX Frontend\n\nReact + TypeScript + Vite frontend for RedirectX.\n\n## Run locally\n\n```bash\nnpm install\nnpm run dev\n```\n\nThe API base URL is read from `VITE_API_BASE_URL` and defaults to `http://localhost:3000`.\n\n## Build\n\n```bash\nnpm run build\n```\n\nThe Vite base path is configured as `/redirectx/` for GitHub Pages deployment. Demo mode loads bundled static JSON from `public/demo/` when the backend demo endpoint is unavailable.\n
